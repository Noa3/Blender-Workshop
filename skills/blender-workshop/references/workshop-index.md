# Blender Workshop library

Start with the [field cards](field-cards.md), or look up a specific topic in the [production atlas](production-atlas.md). Each route ends with a check you can run on your own work. No Blender projects, rendered exercises, third-party models, videos, or caches are included in this skill.

Use the [offline commands and optional labs](portable-use.md) with your local tools. A historical case study records the original test; it does not imply its scene is supplied. Only the included generators are needed for the reproducible examples described in the lab guide.
